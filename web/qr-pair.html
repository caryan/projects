How to pair

  1. Open this page on both laptops. Both must be on the same wifi.
  2. Click Host on one laptop and Join on the other, and allow camera access.
  3. Sit the laptops facing each other about 30–50 cm apart, with screen brightness turned up.
  4. The joining laptop scans the host's code and shows a reply, and the host scans the reply. Both laptops then connect.
  5. No working camera? Each code can also be copied and pasted, for example over AirDrop or iMessage.
How it works

The laptops talk over a WebRTC data channel. To start one, each browser needs a few facts about the other. The browser's full description of those facts runs to 500–1,500 characters, but only the fields below are needed. The page packs them into bytes and spells them out in a 32-letter alphabet (Crockford base32). That alphabet uses QR's compact uppercase mode, so each code is roughly 100–125 characters and makes a small, easy-to-scan QR code. The receiving page rebuilds a complete description from these fields.

FieldBytesWhy it's needed
Header and checksum2Says whether this is the host's code or the reply, and catches mistyped pastes
ICE username and password~23Random per session. Lets each side confirm that connection checks really come from its partner
Certificate fingerprint (SHA-256)32Lets each side verify that the encrypted link really goes to its partner and not to an impostor
Address and port7–19 eachWhere to reach the laptop on the local network: a real IPv4 address (7 bytes), or a hidden .local name (19 bytes) if camera access was refused

Once the page has loaded, no servers are involved. The laptops talk directly to each other, so this only works when both are on the same local network and that network lets devices reach each other. Many guest networks block this.
